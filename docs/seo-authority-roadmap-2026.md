## Localization policy
Every important page must have native English, Dari and Pashto titles, summaries, body copy and metadata. Afghan terminology should be used naturally, including:
- Database / دیتابیس / ډیټابیس
- Warehouse / stock / inventory / گدام / موجودی / ګدام / موجودي
- Software / نرم‌افزار / سافتویر / سافټویر
- IT / ICT / تکنالوژی / ټکنالوژي
- Accounting / حسابداری / حسابات / حسابداري

## Internal linking
Informational articles link to the commercial landing page they support. Commercial pages link to relevant implementation services, products, industry pages and high-value guides. Avoid multiple pages with the same primary intent.

## Publishing standard
No generic AI filler. Each page must answer a real buying, implementation or operational question, include Afghanistan-specific constraints where relevant, and avoid unsupported rankings, client claims or regulatory promises.

## Measurement
Track each cluster in Google Search Console by query and landing page. Review 28-day vs previous-28-day impressions, clicks, CTR and average position. Expand only where impressions or buyer relevance justify additional pages.
